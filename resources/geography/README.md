# Referência geográfica local

Dados públicos de https://github.com/kelvins/municipios-brasileiros (licença MIT incluída), obtidos em 01/10/2026: 5.571 municípios e 27 estados.

Somente coordenadas municipais são utilizadas. Não há envio de endereços de candidatos a serviços externos. A distância é um raio em linha reta entre as coordenadas municipais, não percurso rodoviário nem distância entre endereços. Localidades não identificadas ficam pendentes e não são consideradas elegíveis para seleção presencial/híbrida.
